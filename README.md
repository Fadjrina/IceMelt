# IceMelt
IceMelt is a fun, retro-style Pomodoro timer and event tracker built with React. It uses a unique "melting ice" visualization to help you stay focused during your study or work sessions. 

🎧 The Coding Vibe
This project was built with a specific "coding vibe" in mind: Lo-Fi, Retro, and Highly Focused.

Aesthetic First: The goal was to break away from sterile, minimalist productivity apps. The thick borders, sharp shadows, and pixel-art references (using the VT323 font) are meant to evoke the feeling of playing a 90s handheld game or typing on an old terminal.

The "Chill" Factor: Productivity shouldn't be stressful. The melting ice metaphor is designed to be a gentle, visual reminder of passing time rather than a ticking, anxiety-inducing clock. The built-in rain sounds add to that cozy, "staying indoors to get things done" atmosphere.

Monolithic but Modular (The React Way): Everything lives neatly in a single component structure (for ease of deployment in web environments), but the logic is clearly separated. It's a playground for managing state, intervals, and SVG/CSS visual tricks without over-engineering the architecture.

✨ Features
🍅 Pomodoro Timer with a Twist: Watch the ice cubes melt as your focus time progresses, and see the water level rise!
🎨 Pixel Art Aesthetic: A charming, retro-inspired UI design with satisfying button presses and bold borders.
📅 Event Countdown: Keep track of important upcoming dates (exams, deadlines, events) right next to your timer.
🌈 Multiple Themes: Customize the look of your timer with different flavor themes (Ice, Matcha, Berry, Candy, Sunset).
🌙 Dark Mode: Easy on the eyes for those late-night study sessions.
🎵 Background Sounds: Built-in ambient sounds (like rain) to help you concentrate.
💾 Local Storage: Your username, events, theme choice, and timer settings are automatically saved to your browser.

🚀 Technologies Used
React: The core framework used to build the user interface.
Tailwind CSS: For rapid, utility-first styling.
Lucide React: For crisp, scalable icons.
